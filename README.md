# fast-reader-spritz

Obsidian eklentisi: Spritz tarzı RSVP hızlı okuma paneli

## Kurulum (BRAT ile)

1. Obsidian'da **BRAT** eklentisini kur (Community plugins → Browse → "BRAT").
2. `Ctrl+P` → **BRAT: Add a beta plugin for testing**.
3. Yapıştır: `yasirbilgic/fast-reader-spritz`
4. **Add Plugin**.

Güncelleme: `Ctrl+P` → **BRAT: Check for updates to all beta plugins**.

## Sürüm
`manifest.json` içindeki `version` ile release tag'i eşleşmelidir (şu an: 1.1.0).
